# Files permitted to use Cell<, RefCell<, or UnsafeCell< in a hot-path crate
# (irontraffic-io, irontraffic-runtime, irontraffic-conn, irontraffic-upstream,
# irontraffic-dataplane). See the interior-mutability rule in
# scripts/invariant-lints.sh for why these are banned by default: a tokio
# task migrates between worker threads at any await point, so per-core state
# reached through a Cell is a data race; per-core cells should be relaxed
# atomics instead.
#
# One repository-relative path per file, exactly as it appears in `git
# ls-files`. Matching is EXACT path equality only: never a prefix, a suffix,
# a glob, or a directory. Blank lines and lines starting with `#` are
# ignored. Every entry must be justified with a comment on the line above it
# explaining why that specific file is a legitimate exception, added in the
# same PR that needs it.
#
# The M1 thread-local buffer pool. The RefCell borrow is taken and released
# entirely inside a synchronous closure passed to BufPool::with_current, which
# cannot await, so it cannot be held across a task migration point; a per-core
# atomic cannot express the pool's Vec<BytesMut> free list, which is why this
# is a RefCell exception rather than a rewrite to atomics like the balance
# counters beside it.
