# corpus/paths.txt: the path corpus.
#
# One entry per line: <outcome><TAB><escaped-target>[<TAB><extra>]
#
# <outcome> is `ok` or the exact `RejectReason` variant name in PascalCase.
# Escapes: `\r`, `\n`, `\t`, `\0`, `\\`, and `\xHH`. A line starting with `#`
# is a comment; an empty line is skipped.
#
# <extra> is one of two things, told apart by shape: when it starts with
# `/` it is the expected NORMALIZED PATH bytes (required on every `ok`
# entry, itself escaped the same way) under the DEFAULT policy; otherwise it
# must be one of the five policy names `default`, `keep-dot`, `keep-slash`,
# `keep-both`, `merge-slashes`, naming a NON-DEFAULT policy to run the entry
# under, and a fourth field then carries the expected output for an `ok`
# entry exactly as the third field would for a default-policy row.
#
# Driven by crates/irontraffic-http/tests/corpus.rs's `paths` test:
# NormalizedPath::parse_into under the named policy (default when absent).
